Tree-aggregating LUTs — bounded fan-in, O(log N) depth

Contents · Single table · Charge summation · Aggregator population · Aggregation tree

The scale-to-hundreds story. Model 3 sums N tables by dumping every table's output spikes onto ONE aggregator — its fan-in grows linearly with N. Here we build a binary aggregation tree: each aggregator listens to exactly two children (tables, or lower aggregators) using the same sustained-current-until-readout-clock trick, so every neuron's fan-in stays bounded at 2 while total depth grows only like log₂(N). Four tables → two Level-1 aggregators → one Level-2 aggregator → the summed output spikes.

How it's wired — DETECT · COMPL · ROWS · TAB-OUT · L1-AGG · L2-AGG
  • DETECT / COMPL / ROWS — as in the other models: hyperplane sign-tests (Hk), their complements (Ck = NOT Hk, built by an inhibitory H→C synapse, ┄ dashed), and a 2K one-hot row decoder.
  • TAB-OUT (oj) — each table's OWN output neurons; the winning row drives oj through a delay = α+β·Ot[rt][j], so it fires at a latency encoding the value (bigger = later).
  • L1-AGG — each listens to exactly TWO tables' output-j spikes (purple listening edges), integrates a sustained current until its readout clock, and re-emits the partial sum as latency spikes.
  • L2-AGG (Σj) — listens to the two L1 aggregators' EMITTED spikes (treated as ordinary tables), sums them, and fires the total.

The aggregation tree — bounded fan-in, O(log N) depth

Each aggregator uses the model-3 rule: incoming spikes switch on a sustained current I until a readout clock T, so Vj(T)=I·Σc(T−tc,j) is affine in the partial sum, recovered and re-emitted at t = T + α + β·P. Because an aggregator's output is itself a latency-coded emitter, the next level consumes it identically — so the tree composes.

Level 1: L1a = agg(T0,T1) → Pa = O₀[r₀]+O₁[r₁]  ·  L1b = agg(T2,T3) → Pb = O₂[r₂]+O₃[r₃]
Level 2: L2 = agg(L1a,L1b) → S = Pa+Pb = Σt Ot[rt]  ·  emit t_out = T2 + A + B·S
constants: α=5, β=1, GZt=row-fire+0.6, I=1, T=(last child spike)+0.6, A=5, B=1 · fan-in per aggregator = 2

Scaling — binary tree over N tables

Fan-in per aggregator is constant (2) no matter how many tables; only the depth grows, logarithmically. A binary tree over N leaves has N−1 internal aggregators.

Verified

Over 50,000 random inputs (analysis/tree_aggregator_check.py): each L1 aggregator's membrane decodes to its true partial sum to 1.8e-15, the L2 membrane to the true total to 9.9e-15, and the final emitted summed-spike times decode to Σt Ot[rt] to 9.9e-15 — 100% match (200k/200k dims). Every aggregator has fan-in 2; depth grows as log₂(N).
