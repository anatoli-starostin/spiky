Composing two LUTs — y = LUT₁(x) + LUT₂(x)

Contents · Single-table demo · Two-table composition

Two tables read the SAME input x. Each has its own detector→decoder branch, but both share ONE input population and converge onto ONE shared row of output neurons. Latencies don't sum, so each table deposits its selected output vector as synaptic charge; the shared outputs accumulate O₁[r₁] + O₂[r₂] and then emit real output spikes at latencies encoding the sum.

How the middle layers are wired — DETECT · COMPL · ROWS
  • DETECT (Hk) — one hyperplane sign-test each. After the green CLOCK readout pulse, Hk fires iff its margin ⟨Wk,x⟩+bk ≥ 0 → that spike is address bit k = 1; silence = bit 0. Its incoming edges are the weighted input→detector synapses (Wd=−W), coloured ■ −/■ + by weight.
  • COMPL (Ck) — the negated bit. The CLOCK drives Ck excitatorily, and Hk sends an inhibitory synapse to Ck (drawn ┄ dashed purple), so Ck fires iff Hk did not (Ck = NOT Hk). Every bit is now available as a spike in both polarities.
  • ROWS (2K one-hot) — each row = one address pattern; a K-way coincidence AND. Row r takes one excitatory literal synapse from Hk if r's bit k=1, else from Ck; threshold just under K, so exactly the one row matching the detector bits fires.

Scaling to N tables — neuron & synapse budget

All N tables share the input population, the CLOCK, and the summing output neurons; each table adds one fixed block (2K detectors+complements + 2K decoder rows). For this shape (D=6, K=3, 2K=8, Dout=4):

Neurons = (2 + D + Dout) + N·(2K + 2K) = 12 + 14·N
Synapses = 1 + N·(D·K + 3K + K·2K + 2K·Dout) = 1 + 83·N
