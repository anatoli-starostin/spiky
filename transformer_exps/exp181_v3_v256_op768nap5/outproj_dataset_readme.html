Out-Projection Activity Dataset

Synthetic dataset capturing the input/output behavior of the out_proj LUT module at layer 3 (middle layer) of a trained LUT-based transformer.

1. Source Model

The data was generated from exp181_v3_v256_op768nap5, a LUT-based causal language model trained on byte-level text (vocab size 257, context length 32).

Architecture: LUTTransformerV3Softmax

Each of the 6 transformer blocks follows a classic attention pattern, but replaces all linear projections with Lookup Table (LUT) modules:

x  -->  [Score LUT]  -->  attention scores  [B, T, T, H, 1]
x  -->  [Value LUT]  -->  values            [B, T, H, d_v]
        softmax(scores) @ values            [B, T, H, d_v]
        LayerNorm
        [Out-Proj LUT]                      [B, T, E]
        residual + LayerNorm

Out-Proj LUT Hyperparameters

The out_proj module is a pointwise (per-token) LUT that maps the concatenated multi-head attention output back to the embedding dimension:

ParameterValueDescription
input_dim64H × d_v = 4 × 16
n_outputs32= embedding_dim
n_heads1single-headed projection
n_anchor_pairs (nap)525 = 32 entries per table
tables_per_head (tph)768768 lookup tables
anchor_sampling_policyfull_coverageall input dim pairs tiled across tables
smooth_modefalsehard (non-differentiable) lookups
n_alternatives1single lookup per table

Each table compares 5 pairs of input features to produce a 5-bit index (0–31), then looks up a weight vector of size 32. The outputs of all 768 tables are summed to produce the final 32-dimensional output. The input to out_proj is LayerNorm-normalized.

2. Data Format

File: outproj_dump.parquet (Apache Parquet, zstd compressed, ~522 MB)

Schema

ColumnTypeDescription
x1 … x64float32Out-proj input (post-LayerNorm attention output)
y1 … y32float32Out-proj output (before residual addition)

Total columns: 64 + 32 = 96. All data is from layer 3 (middle layer of 6).

Reading the data

import pandas as pd
df = pd.read_parquet(outproj_dump.parquet)
# or with pyarrow directly:
import pyarrow.parquet as pq
table = pq.read_table(outproj_dump.parquet)

Data Generation

  • 10,000 batches of 128 samples, sequence length 32
  • Only the last token position (index 31) is recorded per sample
  • Layer 3 only → 10,000 × 128 = 1,280,000 rows
  • Model in eval mode (no dropout, no gradient)
