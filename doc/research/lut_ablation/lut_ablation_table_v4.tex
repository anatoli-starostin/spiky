\section*{Protocol}
\textbf{Architecture:} LUT transformer, $E=384$, 6 layers, 6 attention heads. FFN = \code{CompressionMultiHeadLUT} with $H=4$ heads $\times$ $tph=128$ tables
($P=H\cdot tph=512$ tables per token), $d_{in}=d_{out}=48$, $n=8$ anchor pairs per table ($K=2^n=256$ cells); \code{compress} $384\to192$, \code{decompress} $192\to384$.
\textbf{Training:} 16{,}000 steps, batch size 48 (24576 tokens), untied embeddings, LUT tables without weight decay.
\textbf{Eval:} \code{evaluate\_bpb\_fixed}, 48 rows $\times$ 100 steps, first 12 rows skipped.

\medskip
\noindent\fbox{\parbox{\dimexpr\linewidth-2\fboxsep-2\fboxrule\relax}{%
\textbf{One seed per row.} Every validation bpb below is a single run, and there are \textbf{zero seed replicates} at this geometry.
The only LUT seed-noise figure on record is a 4K three-seed sd of 0.009642, a \emph{lower bound}; ``units'' below are multiples of it (the vanilla two-seed range at 16K is 0.00335).
\textbf{Every Gen-3 difference in Table B is inside one unit}: 3.3 vs 3.1 $-$0.0035 (0.4), 3.4 vs 3.3 $-$0.000016 ($<$\,0.01), 3.5 vs 3.4 $-$0.0056 (0.6).}}

\section*{Counting convention}
\begin{itemize}\setlength\itemsep{0pt}
\item Core LUT only, per token, one layer. The \code{compress}/\code{decompress} projections are identical in every row and excluded (147,456 MACs forward).
\item \textbf{FLOP} = one scalar float operation ($+,-,\times,\div$, a comparison, $|\cdot|$, $\exp$, $\log\sigma$, $\sigma$). \textbf{MAC} = a multiply accumulated into a sum; 1 MAC = 2 FLOPs,
  included in the FLOP column. Memory reads and integer work are not counted.
\item \textbf{Forward} = inference. \textbf{Backward} = all additional training arithmetic, including per-table gradients of per-layer scalars and training-only regularisers
  (amortised over the 24,576 tokens of a step).
\end{itemize}

\noindent\textbf{Notes to Table B.}
\begin{itemize}\setlength\itemsep{0pt}\footnotesize
\item[\note{e}] Dominated by $2Kd$: every table's $K$ rows are read; several \code{[tokens, 512, 256]} fp32 buffers of about 12.9\,GiB at 24,576 tokens.
\item[\note{f}] Re-score of the saved run under the corrected eval (0 missing keys); its in-run batch-coupled number was 1.191455.
\item[\note{g}] Forward: $\beta m_j$ replaces $2m_j$, plus $\times\gamma$ and $+g$ per table ($+2$ vs 3.1). Backward: the input term as 3.1 plus 3 scalar operations, and the
  per-table accumulation of the parameter gradients ($\partial g$ 2, $\partial\log\gamma$ 3, $\partial\log\beta$ $2n+2$); 3.4 drops $\partial g$. Scalar multiplies only, so no MACs are added.
\item[\note{h}] Training only, once per step: $P\,n\,2^{n-1}=524{,}288$ cell pairs per layer, $3d$ FLOPs and $d$ MACs per pair in each direction (150,994,944 FLOPs, 50,331,648 MACs per layer per step),
  i.e. $+6{,}144$ FLOPs and $+2{,}048$ MACs per token over 24,576 tokens. Inference cost is 3.4's.
\end{itemize}

\section*{The Gen-3 form (one seed each)}
\begin{itemize}\setlength\itemsep{1pt}
\item \textbf{Margin score with per-layer trainable $\beta$ and $\gamma$ (3.4). Drop $g$:} freezing it leaves bpb ($-$0.000016 vs 3.3) and the $\gamma$ profile (max $|\Delta\gamma|$ 0.016) unchanged.
  Trained $\gamma$ 1.04--1.60, highest mid-depth; $\beta$ 1.76--2.17 and nearly irrelevant to the score's shape. Both were still drifting at 16K.
\item \textbf{Cell TV (3.5): $-$0.0056 vs 3.4, a mild regularisation benefit}, not established (0.6 units). \textbf{The mechanism is mostly table shrinkage, not smoothing:}
  table L2 norms fell to 0.22--0.35$\times$ of 3.4's, while the scale-free ratio $\overline{\|W[c]-W[c']\|^2}/\overline{\|W[c]\|^2}$ (2.0 for independent random cells)
  moved only from 1.74--1.95 to 1.34--1.57 across layers.
\end{itemize}

\section*{Where the code differs from the original brief}
\begin{itemize}\setlength\itemsep{0pt}
\item 1.1's input gradient is a surrogate (the derivative of 1.2's blend); its weights update only the addressed row.
\item The status report's $u(\delta)=0.5/(T+|\delta|)$ has a temperature; the code's $0.5/(1+|u|)$ has none (\code{l\_projection.py:96}, \code{lutorch.cu:797}).
\item Gen 2's hybrid\_smooth weight $\sigma(-2\rho_{j^\star}/T_{sel})$ is a temperature-controlled soft-sign, not Gen 1's $U(u)$.
\item The margin score is LookupFFN's kernel $S_t\prod_j\sigma(2m_j)$, not $\min_jm_j$; 3.3--3.5 learn its 2 (as $\beta$) and add an exponent $\gamma$.
\end{itemize}
