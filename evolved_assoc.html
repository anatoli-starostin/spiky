An evolved spiking net that MEMORIZES arbitrary associations

Contents · Neuroevolution of a Dale-law STDP associative memory

The demos ①–⑦ show hand-built or weight-evolved networks that compute a fixed function. This one is different: neuroevolution discovered a tiny recurrent spiking network that can be TAUGHT. In each episode it's shown two brand-new, arbitrary input→output-order mappings and must store them via spike-timing plasticity (STDP), then reproduce each output order from its input alone. Because the targets are random every episode, no fixed feedforward function can win — only genuine storage scores. It obeys Dale's law (a neuron is excitatory or inhibitory, not per-synapse), inhibition is fixed and fast (delay 1), and only excitatory synapses learn.

The evolved network

Inputs (cyan squares) → excitatory (green) & inhibitory (red) neurons → 4 outputs (ringed). Solid = feedforward, dashed = recurrent/lateral (where the taught order is stored). Excitatory edges are plastic with an evolved delay; inhibitory edges are fixed, delay 1.

Why this matters

This is a proof-of-concept of learning-to-learn by evolution: rather than evolving the weights of a fixed solver, evolution shaped a topology + plasticity substrate that can rapidly memorize new associations at "inference" time via STDP. The winner reaches mean storage-gain ~0.67 and generalizes to unseen random mappings — a genuine, if small, spiking associative memory discovered from scratch under biological (Dale) constraints. Dynamics here are precomputed from the real evolved network (the in-browser page shows its actual recall behaviour).
