Composing two LUTs — y = LUT₁(x) + LUT₂(x)

Contents · Single-table demo · Two-table composition

A real network is a SET of tables whose selected output vectors are added. Latencies don't sum — so the output moves into the charge domain: each table's selected row deposits its stored output vector as synaptic charge onto shared output neurons, whose membranes accumulate O₁[r₁] + O₂[r₂]. Same input x drives both tables.

Shared output neurons — charge accumulates the SUM from BOTH tables

Each shared output membrane gets charge from BOTH winning rows: ■ Table 1's O₁[r₁][j] then ■ Table 2's O₂[r₂][j], accumulating to S[j]=O₁[r₁][j]+O₂[r₂][j]. The white marker (▮) is the summed membrane; a fixed-window readout converts it to an output latency.

Verified

Over 50,000 random inputs (analysis/composition_check.py): the charge-accumulated output equals the true O₁[r₁]+O₂[r₂] to 0.00e+00, and the latency readout decodes back to the sum to 1.3e-15 — 100% match. Summing latencies instead does NOT work — the point of the charge domain.
