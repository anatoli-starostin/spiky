Drag xi ∈ [−1, 1]. Per hyperplane k: margin m_k = ⟨W_k,x⟩ + b_k, bit = [m_k > 0]. The 3 bits pick a row; the row's stored 4-vector is the LUT output.

2 · Pure spiking circuit (event-driven simulation)

A real network of leak-free integrate-and-fire neurons wired by synapses (weight and conduction delay). Every spike is emitted by the simulator; the bits, winning row and output are read back from the emergent spikes, no analytic margin. START → inputs → CLOCK gates the detectors → complements (feedforward inhibition) → one row wins by 3-way coincidence → outputs fire with the stored value carried in the delay.

Time increases left → right (← earlier · later →). Input rows stay x0…x5 top-to-bottom; each spikes at its own ti from the table above.
