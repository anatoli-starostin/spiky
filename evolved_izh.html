An evolved spiking neural network that ranks by spike timing

Neuroevolution found this 16-neuron Izhikevich network for a latency-ordering task: six inputs arrive as spikes whose timing encodes a value (bigger → earlier), and the four output neurons must fire in the order that matches an oracle ranking. Fitness = Kendall tau-b between the output first-spike order and the target. Below the actual network runs in your browser — a faithful port of the simulator — so you can watch spikes propagate and the output order emerge. Neurons are the two canonical Izhikevich-2006 types, RS (excitatory) and FS (inhibitory), chosen per-neuron by evolution.
