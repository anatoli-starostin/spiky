Pure spiking circuit — event-driven simulation (nothing computed as logic)

A genuine network of leak-free integrate-and-fire neurons wired by synapses (weight and conduction delay). Every spike below is emitted by the simulator; the bits, the winning row and the output vector are read back from the emergent spikes — no analytic margin anywhere. START → inputs → CLOCK gates the detectors → complements (feedforward inhibition) → one row wins by 3-way coincidence → outputs fire with the stored value carried in the delay.
